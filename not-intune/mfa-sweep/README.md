# MFA

## MFASweep

MFASweep is not vendored here. Get it from the author:

https://github.com/dafthack/MFASweep

It is Beau Bullock's tool (@dafthack), MIT licensed. An earlier revision of
this repository carried a copy of `MFASweep.ps1` in this folder with no
attribution and no link, which read as though it were ours and which would
have aged silently against upstream. A security assessment tool that quietly
falls behind its source is worse than no copy at all, so the copy is gone and
this pointer replaces it.

Run it against a tenant you are authorised to test.
